# Общие контракты

Пакет `@gate/contracts` экспортирует Zod-схемы и выведенные из них TypeScript-типы: `Session`, `Message`, `History`, `SendMessage`, `StreamEvent`, `ApiError`.

- Session: публичный ID, срок действия, серверное время.
- Message: ID, ID сессии, порядок, роль, текст, статус, время создания и срок хранения.
- History: текущая сессия, упорядоченная страница сообщений и курсор предыдущей страницы.
- SendMessage: непустой обрезанный текст до 16000 символов и UUID requestId.
- StreamEvent: начало ответа, текстовый фрагмент, завершение, ошибка с необязательным частичным сообщением.
- ApiError: объект error с машинным code и безопасным message.

Схемы проверяют UUID, ISO-время, роли и статусы. Обе стороны валидируют неизвестные внешние данные. Схема `done` описывает форму события; допустимость перехода статуса дополнительно проверяет прикладная логика.

Ограничения продукта в одном месте: SESSION_TTL_MS, HISTORY_TTL_MS, CONTEXT_LIMIT, MAX_INPUT_LENGTH. Изменять их вместе с тестами и документацией.
