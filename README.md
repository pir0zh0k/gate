# gate

Анонимный ИИ-диалог: React 19 + TypeScript + Tailwind/FSD, Fastify/MVC и PostgreSQL в Docker.

## Правила продукта

- Один диалог на сессию; сессия действует **1 час от создания**.
- Каждое сообщение хранится **6 часов от создания**. После истечения сессии доступ к старому диалогу прекращается, даже если записи еще есть в БД.
- В контекст ИИ передаются последние **10** завершенных сообщений, включая текущий запрос. Незавершенные ответы не используются.
- Секрет сессии — HttpOnly cookie; localStorage — только валидируемый кеш, не авторизация.
- OpenAI Responses API, модель `gpt-5.6-terra`; ключ используется только сервером.

Правила отсчета сроков выбраны как рабочие предположения из плана, а не отдельные подтвержденные требования пользователя.

## Подготовка

Node.js 22.12+ (для Node 22) либо актуальная поддерживаемая Node 24+, pnpm 10.34.5, запущенный Docker.

1. `pnpm install --frozen-lockfile`
2. Скопировать `.env.example` в `.env`, задать серверный `OPENAI_API_KEY`. Не публиковать файл и ключ.
3. `docker compose up -d postgres`
4. `pnpm db:migrate`
5. `pnpm dev` — только при необходимости локального запуска.

Frontend: http://localhost:5173, API: http://127.0.0.1:3001. Vite проксирует `/api`, браузер работает с одним origin. `APP_ORIGIN` должен точно совпадать с адресом frontend.

Без API-ключа приложение не подменяет ИИ фиктивным ответом: генерация возвращает понятную ошибку конфигурации. Контролируемый адаптер используется только в автоматических тестах.

## Проверки

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `pnpm format:check`
- `TEST_DATABASE_URL=… pnpm test:integration` — только отдельная тестовая PostgreSQL, не рабочая БД.
- `TEST_DATABASE_URL=… pnpm test:e2e` — после сборки и установки Chromium: `pnpm exec playwright install chromium`.

## Структура

- `apps/web` — интерфейс, поток, кеш.
- `apps/api` — HTTP, сессии, хранение и ИИ-интеграция.
- `packages/contracts` — runtime-схемы и общие TypeScript-типы.
- `docs` — документация модулей и план.
