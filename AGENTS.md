Данный проект - ИИ-гейт.

Стек:
1. Frontend - React 19, TypeScript, Tailwind, FSD
2. Backend - Fastify, TypeScript, MVC
3. База данных - PostgreSQL в docker-контейнере

Авторизация анонимная, после нее сразу попадаем на форму с вводом запроса

Обработка запроса к ИИ стриминговая, можем использовать любой гейт

История каждой сессии должна быть сохранена в базу данных

В контексте ИИ держим последние 10 сообщений

Для хранения локальной сессии используем cookie
Для кеширования истории используем local-storage

Правила и ограничения:
1. Не повторяемся, если один и тот-же код можно переиспользовать
2. Не дублируем компоненты
3. БД должна быть проиндексирована
4. Соблюдай принципы SOLID, DRY, KISS, YAGNI
5. Запрещено использовать any, вместо него лучше используй unknown с дальнейшим приведением типа
6. Весь код должен быть строго типизирован. Не типизированные участки не допустимы.
7. Обязательно веди минимальную документацию по каждому модулю в папке ./docs
